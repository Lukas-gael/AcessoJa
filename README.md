# Acesso Já

**Autor:** Lucas Gabriel Moreira dos Santos
**RU:** 5085283

## Sobre o projeto

O **Acesso Já** é um aplicativo mobile criado para facilitar o acesso e o
contato com instituições e serviços essenciais — como emergência, energia,
água, órgãos públicos e assistência social — voltado especialmente para
pessoas com baixo conhecimento tecnológico ou dificuldade em navegar por
ambientes digitais. A proposta é reunir, em um único lugar, contatos
telefônicos, sites e horários de atendimento organizados de forma simples e
direta, sem exigir familiaridade prévia com aplicativos ou internet.

## Escopo

Este projeto contempla, por enquanto, apenas os serviços do município de
**Curitiba (PR)**. Por se tratar de um desenvolvimento individual, optei por
limitar o escopo a uma única cidade, garantindo dados corretos e
atualizados dentro do tempo disponível para o projeto.

## Tecnologia

O aplicativo foi desenvolvido em **Python**, utilizando o framework
**Flet** para a construção da interface mobile.
